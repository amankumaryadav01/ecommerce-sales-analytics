# 🛒 E-commerce Sales Analytics

An end-to-end **E-commerce Sales Analytics** project that analyzes online retail transaction data to uncover meaningful business insights, understand customer purchasing behavior, evaluate product performance, and identify revenue trends.

The project transforms raw transactional data into actionable business insights using Python, Pandas, and data visualization techniques, helping support data-driven decision-making.

## 📊 Project Overview

This project analyzes an **Online Retail dataset** containing transaction-level information such as products, customers, invoices, quantities, unit prices, and countries.

The main objective is to understand:

- Which products generate the highest revenue?
- Which countries contribute the most to sales?
- How do sales change over time?
- Which customers contribute the most revenue?
- How do product returns affect overall revenue?
- Where can the business improve its performance?

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone [https://github.com/amankumaryadav01/ecommerce-sales-analytics.git](https://github.com/amankumaryadav01/ecommerce-sales-analytics.git)
```

### 2. Navigate to the project directory

```bash
cd ecommerce-sales-analytics
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 5. Run the analysis

Open the project notebook and execute the cells sequentially to explore:

- Data cleaning process
- Exploratory analysis
- Visualizations
- Business insights
